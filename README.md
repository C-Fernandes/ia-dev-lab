# ia-dev-lab

Projeto de laboratório para testar a eficácia de assistentes de IA no desenvolvimento de software.

## Visão geral

O repositório reúne pequenos scripts e experimentos usados para avaliar como
assistentes de IA se comportam em tarefas comuns de desenvolvimento. O código
focado em regra de negócio fica na pasta `src/`.

## Requisitos

- Python 3

## Uso

Executar o script inicial de saudação:

```bash
python3 src/hello.py
```

Saída esperada:

```
Olá, mundo!
```

## Validadores

- `validador_email`
- `validador_email_simples`
- `validador_cor_hex`

## Convenções

- Código de regra de negócio deve ficar em `src/`.
- Não utilizar bibliotecas externas sem que estejam documentadas.
