## Sobre o projeto

Projeto de laboratório para testar a eficácia de assistentes de IA no desenvolvimento de software.

## Comandos

- `python3 src/hello.py` -> Executa o script inicial de saudação.

## Convenções de código

- O código focado na regra de negócio deve ser mantido dentro da pasta `src/`.

## Não fazer

- Não utilize bibliotecas externas sem que estejam documentadas.
